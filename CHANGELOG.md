# Changelog

## 1.0.0
- First release. The behaviour of Cartur's Build Camera 1.1.1 (its 1.0.0 source plus the 1.0.1 - 1.1.1 fixes), with The Shack's settings as defaults: **Y** toggles, 2 m pickup range and 1x Wisplight range.
- Settings sync and the version check now use Jotunn. A server with this mod never turns away players without it.
- If Cartur's Build Camera or Azumatt's Build Camera is also installed, this mod switches it off and runs the camera itself.
- GPL-3.0, with the full source included as `source.zip`.
